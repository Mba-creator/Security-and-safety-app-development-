Project Overview
This project involves the design and development of a modern, responsive website for Seeds Of Change. The goal is to create an online presence that effectively communicates the organisation's services and values.

Website Goals and Objectives
- Primary Goal: To generate leads through a contact form.
- Secondary Goal: To establish credibility and provide key information to potential clients.

Key Features and Functionality
- Responsive navigation menu
- Contact form with validation
- Gallery or portfolio section
- Clean and modern design
